# MySimpleListApp

**MySimpleListApp** é um aplicativo simples de lista de compras desenvolvido em Android utilizando Kotlin. Ele permite que o usuário visualize itens de uma lista de compras, adicione novos itens e veja as informações dos produtos de forma simples e intuitiva.

## Funcionalidades

- Exibição de uma lista de itens de compras com informações sobre o nome, descrição, preço e imagem.
- Adição de novos itens à lista através de um formulário.
- Utilização de **Floating Action Button (FAB)** para abrir o formulário de adição.
- Interface intuitiva utilizando **RecyclerView** para exibição da lista e **DialogFragment** para o formulário de adicionar itens.

## Tecnologias Usadas

- **Kotlin**: Linguagem principal utilizada no desenvolvimento.
- **Android SDK**: Utilização do Android SDK para desenvolvimento de aplicativos móveis.
- **RecyclerView**: Exibição da lista de itens com rolagem.
- **DialogFragment**: Interface para captura de dados via formulário.
- **Floating Action Button (FAB)**: Botão flutuante para interação do usuário.
- **Material Design**: Utilização de componentes do Material Design para criar uma interface moderna e acessível.
